# claude-code-happyoh

Claude Code 작업용 프로젝트 저장소입니다.

## 테트리스 (`Tetris.html`)

설치 없이 파일을 더블클릭하면 브라우저에서 바로 실행되는 1인용 테트리스입니다.

- **모드**: 마라톤(150줄), 스프린트(40줄 타임어택), 울트라(2분 점수 도전)
- **규칙**: SRS 회전·벽차기, 7-bag, 홀드, 고스트, 다음 블록 5개, 락 딜레이(0.5초, 최대 15회 연장), T-스핀, 콤보, 백투백, 퍼펙트 클리어
- **실시간 성적**: 점수, 시간, 줄, 레벨, PPS, KPP, 콤보/B2B, 최고 기록 대비 차이
- **기록**: 게임이 끝나면 이 폴더의 `tetris-records.json`에 자동 저장됩니다. 기록 화면에서 순위·최고 기록·추이 그래프를 볼 수 있고, JSON으로 내보내기/가져오기도 됩니다.
  - 처음 한 번 타이틀 화면의 **저장 폴더 선택**을 눌러 `Tetris.html`이 있는 폴더를 고르고 쓰기를 허용하면 됩니다. 브라우저는 보안상 스스로 디스크에 쓸 수 없어서 이 허용이 필요합니다.
  - Chrome·Edge에서만 됩니다. 다른 브라우저나 폴더를 연결하기 전에는 브라우저(localStorage)에만 남고, 폴더를 연결하면 두 쪽 기록을 합쳐 파일에 씁니다.
  - 브라우저를 다시 열었을 때 권한을 다시 물으면 **권한 허용**을 누르세요. 권한 창에서 "방문할 때마다 허용"을 고르면 다음부터는 묻지 않습니다.
- **설정**: 키 배치, DAS/ARR, 소프트 드롭 속도, 고스트·격자·흔들림·효과음

기본 조작: `← →` 이동, `↓` 소프트 드롭, `Space` 하드 드롭, `↑`/`X` 회전, `Z` 반대 회전, `A` 180°, `C` 홀드, `Esc` 일시정지, `R` 재시작

규칙 엔진 자체 테스트는 주소 뒤에 `?test`를 붙여 열면 실행됩니다 (`Tetris.html?test`).
