    페이지를 탭해서 선택한 뒤 아래 [그룹으로 추가]를 누르세요. 다른 페이지를 또 선택해서 그룹을 여러 개 만들 수 있어요.

    쉼표로 구간을 나누고, 범위는 하이픈으로 적으세요. 입력 후 [그룹으로 추가]를 누르세요.

    삭제할 페이지를 탭해서 선택한 뒤 [적용]을 누르면 미리보기에 바로 반영돼요. 확인 후 저장하세요.

    이동할 페이지를 하나 이상 탭해서 선택하세요. 번호는 현재 순서 기준이라 이동할 때마다 바뀝니다.

    이동할 위치를 선택하세요.

    추가할 위치를 선택하세요. "특정 페이지 뒤"를 고른 뒤 위 기준 PDF 썸네일을 탭하면 그 페이지 뒤로 바로 지정돼요.

    회전할 페이지를 탭해서 선택한 뒤 아래 버튼을 누르면 미리보기가 바로 회전돼요. 확인 후 저장하세요.

      화살표로 순서를 바꿀 수 있어요. 이미지를 탭해서 여러 장을 선택하면 한 페이지로 묶을 수 있어요(세로 사진은 1장, 가로 사진은 2~3장을 묶는 식으로 사용하세요).

      JPG·PNG 파일만 지원해요. 묶지 않은 이미지는 한 장씩 A4 페이지에 꽉 차게, 묶은 이미지는 한 페이지 안에 위아래로 나눠 배치돼요. 각 페이지 위/아래에 짧은 설명 글(한글 가능)도 선택적으로 넣을 수 있어요 — 처음 한 번 한글 글꼴을 추가로 내려받아요.

      이 암호를 입력해야 파일을 열 수 있어요. 암호를 잊으면 복구할 수 없으니 꼭 기억해 두세요.
